= sf-time-chrome-extension

A Google Chrome extension for applying planned time to selected SAP SuccessFactors days.

== Apply planned time to selected days

Select days using the checkboxes in the left pane, then click the green
*Complete selected days* button beside *Apply Planned Time*.
The extension opens each selected day and invokes the existing planned-time
action, including its save behavior, before moving to the next day.
The selection is captured at the start because SuccessFactors clears it after saving.

For days with absences, the extension reads the absence records and creates only
the complementary working-time spans within the planned schedule. Unpaid breaks
remain excluded, and credited absence time plus work must total eight hours.
For example, with planned work from 08:00–12:00 and 13:00–17:00, an absence from
10:00–14:00 credited as three hours produces work from 08:00–10:00 and 14:00–17:00.
Full-day vacation needs no work entries and processing continues to the next day.

Partial absences require clock times and an eight-hour planned schedule. The batch
stops before creating entries if durations are inconsistent, the schedule has
dynamic breaks, or the day already has working-time entries. Duration-only partial
leave requires manual handling because it does not identify which hours are absent.

If a day cannot be applied or a save cannot be confirmed, processing stops and
a message reports how many days completed. Check the reported day before retrying;
previously completed days have already been saved. Finish or discard existing
edits before starting, and let processing finish before navigating elsewhere.

The content script runs in the page's `MAIN` world to access SAP UI5 controls.
It depends on the SuccessFactors control IDs and save state represented in the
saved page; changes to the application may require updating the extension.

== How to run

No build step or dependencies are required. Use a current version of Google Chrome.

. Open `chrome://extensions/`.
. Enable *Developer mode*.
. Click *Load unpacked* and select this repository's directory (containing `manifest.json`).
. Open or refresh a matching SuccessFactors page to load the content script.

== How to update during development

After editing files or pulling changes, open `chrome://extensions/` and click
the extension's *Reload* button. Then refresh the SuccessFactors tab so it uses
the updated content script.

== Tests

Run `node --test tests/*.test.cjs` with Node.js.
These tests simulate UI5 navigation and saving; they do not contact SuccessFactors.
To verify the integration, load the extension, select two eligible days in a test
timesheet, and confirm that both receive their own planned entries and an unchecked
day remains unchanged. Also verify that a day with an unavailable native action
stops the batch with a progress message.
