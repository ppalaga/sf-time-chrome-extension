= sf-time-chrome-extension

A Google Chrome extension stub for automating SAP SuccessFactors time entry tasks.

== How to run

No build step or dependencies are required. Use a current version of Google Chrome.

. Open `chrome://extensions/`.
. Enable *Developer mode*.
. Click *Load unpacked* and select this repository's directory (containing `manifest.json`).
. Open or refresh a matching SuccessFactors page to load the content script.

== How to update during development

After editing files or pulling changes, open `chrome://extensions/` and click
the extension's *Reload* button. Then refresh the SuccessFactors tab so it uses
the updated content script.
